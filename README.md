# Сервис почтовых рассылок

___

Базовое приложение для отправки почтовых сообщений .
___
## *Инструкция по установке*

1. Клонируйте репозиторий:

[GitHub](https://github.com/Kristina-Maximova/CustomerService/tree/develop)

2. Установите зависимости:
 - Убедитесь, что у вас установлен Poetry.
 - Если нет, установите его, следуя [инструкциям на официальном сайте](https://python-poetry.org/docs/#installation).

3. В корне проекта создайте файл .env по образцу .env.example

4. Выполните миграции:
```
python manage.py migrate
```
___
## *Почтовый сервис*
Для использования приложения используетс регистрация пользователя по эл.почте.

В приложении есть страницы:
- *Главная*, 
- *Сообщения*, 
- *Получатели*.
- *Рассылки*.

### Использование сервиса:
1. Зарегистрированный пользователь имеет возможность создания, просмотра, редактирования и удаления рассылок, а также может отправлять выбранные рассылки.
2. Есть возможность контроля группой менеджеров
для просмотра и остановки рассылок.

---
Команды для применения администратором на сервере:
```bash
add_managers
create_admin
send_all_mails
send_the_mailing <mailing id>

```
